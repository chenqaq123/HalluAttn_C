\section{Reproducibility Appendix}
\label{sec:appendix}

\paragraph{Per-bin AUROC.}
A full per-bin breakdown (AUROC for every method in every position bin) accompanies the released code and reproduces Figure~\ref{fig:perbin}. The main paper reports aggregate, within-bin, matched-pair, same-object, and residual metrics because those are the controls needed to separate position shortcuts from object-evidence scores.

\paragraph{Audited result artifacts.}
All table numbers in the main paper are checked by \texttt{paper/scripts/check\_audited\_numbers.py}. The checker reads the detection baseline metrics from \texttt{detection/baselines/results/coco\_llava\_7b\_baselines/metrics.json}, attention-only mitigation metrics from \texttt{mitigation/results/coco\_llava\_7b\_attention\_only/}, semantic-neighbor subset metrics from \texttt{mitigation/results/semantic\_neighbor\_audit/attention\_only\_subset\_eval/}, OWLv2 CHAIR detection metrics from \texttt{detection/baselines/results/owlv2\_region\_detection/owlv2\_region\_detection\_metrics.json}, attention-shift audit metrics from \texttt{mitigation/results/coco\_llava\_7b\_attention\_audit/}, and OWLv2 POPE verifier metrics from the corresponding OWLv2 semantic-neighbor audit directories.

\paragraph{TDEV calibration.}
For CHAIR mention detection, the reported two-stage region score uses $\tau_l=0.10$, $\tau_h=0.16$, and $\tau_m=-0.15$, matching \texttt{detection/scripts/evaluate\_owlv2\_region\_detection.py}. For POPE direct verification, thresholds are calibrated on the random split with the semantic penalty objective and are $\tau_l=0.10$, $\tau_h=0.16$, and $\tau_m=-0.15$. For the vanilla gate, the calibrated thresholds are $\tau_l=0.04$, $\tau_h=0.12$, and $\tau_m=-0.20$. The hybrid gate-plus-rescue rule uses the same gate thresholds plus a conservative rescue branch with $\tau_h^{r}=0.50$ and $\tau_m^{r}=-0.10$. These settings are stored in \texttt{mitigation/results/semantic\_neighbor\_audit/owlv2\_two\_stage\_direct/two\_stage\_config.json}, \texttt{mitigation/results/semantic\_neighbor\_audit/owlv2\_two\_stage\_gate/two\_stage\_config.json}, and \texttt{mitigation/results/semantic\_neighbor\_audit/owlv2\_hybrid\_region\_rule/hybrid\_config.json}.

\paragraph{Score caching.}
OWLv2 image-object scores are cached as compressed NPZ files with image keys, object names, and score matrices. The same cache format is used by the POPE and CHAIR audits, so expensive region scoring is separated from deterministic calibration, table generation, and number checking.
